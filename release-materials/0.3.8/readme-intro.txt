Skyrim Text Bridge 0.3.8

Adds an optional native input-state/reset API for FavoriteWheel 0.2.7.
Unicode commits still use Skyrim CharEvents. Ctrl+A/C/X/V editing shortcuts
remain available outside composition; pending commits block confirmation keys.
Use the configured IME toggle (F8 by default) in the outfit name field.
The native integration needs in-game verification with your input method.

Source: RELEASE-NOTES-0.3.8.md. Existing configuration and requirements apply.
