Replaced the desktop candidate window with an in-game ImGui HUD panel through SKSE Menu Framework. Keeps panel style settings, input method name and exit notifications, and includes RaceMenu automatic activation. SKSE Menu Framework and a configured Chinese font are now required. Exclusive fullscreen and the new rendering path still need game testing.
